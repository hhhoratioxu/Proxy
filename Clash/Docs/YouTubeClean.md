# YouTube Clean 与 Clash / Mihomo

Clash/Mihomo 标准核心没有本插件所需的 HTTPS 响应体 JavaScript 改写能力，普通域名分流不能等价实现原生 YouTube 去广告、双语字幕或底部按钮隐藏。本目录提供能力说明。

YouTube Clean 为五种支持脚本的客户端各保留一个当前入口，详见 [所有客户端安装入口](../../README.md)。实际广告效果尚待手机验证。
