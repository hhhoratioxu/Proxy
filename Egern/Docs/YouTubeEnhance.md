# YouTube 增强 · Egern

[导入 YouTubeEnhance.yaml](https://raw.githubusercontent.com/hhhoratioxu/Proxy/main/Egern/script/YouTubeEnhance.yaml)

在 Egern「模块」中添加此远程地址并启用。YouTube 的 HTTPS 内容处理需要已安装并信任的解密证书；模块包含所需主机范围，并自动加载固定版本的运行脚本。

默认启用已识别广告和界面字段处理、最高可用画质、上传入口隐藏、小游戏和商店内容隐藏。Shorts 和竖屏直播隐藏默认关闭；原生下载实验选项默认关闭。

这是原有 gholts / IBL3ND 模块的当前配置入口，运行代码由上游提供；没有把第三方实现标为原创。脚本和服务接口适配不代表账号获得付费权益，实际效果取决于 YouTube 客户端和服务端行为。
