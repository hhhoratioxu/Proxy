按 Clash、Loon、Egern、Surge、Shadowrocket、QuanX 六个客户端分类的个人规则、模块、脚本与图标配置。

各客户端统一使用小写 rule/ 存放分流规则，script/ 存放 JS、模块、插件、重写和任务配置；说明文档放在 Docs/。旧目录地址已迁移，订阅和导入链接请按[目录迁移说明](./Clash/Docs/Directory-Migration.md)更新。

图标导入入口见各客户端的 README。共用 PNG 图库保存在 `Loon/Icons/`，Parsec 分流文档保存在 `Clash/Docs/`。

早期根目录 `Icons/` 图标订阅地址和 `Docs/Parsec.md` 文档地址已迁移，请从各客户端入口使用当前链接。本次目录统一也更新了规则、模块和脚本地址，详见[目录迁移说明](./Clash/Docs/Directory-Migration.md)。

A personal collection of rules, modules, scripts and icon configurations organized by six clients.

Each client uses lowercase rule/ for routing lists and script/ for JavaScript, modules, plugins, rewrites and task resources. Documentation lives in Docs/. Existing resource URLs changed; see the [directory migration guide](./Clash/Docs/Directory-Migration.md) before updating imports.

Each client keeps only the current production version of a plugin, using stable script filenames. Previous versions remain available in Git history.
