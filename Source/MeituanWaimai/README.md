# 美团外卖去广告 0.2.0 源码快照

此目录仅存在于固定的源码提交中。当前主分支的各客户端 script/ 只保留一个可导入入口，入口按不可变提交下载本次运行脚本。

- core.js 是独立编写的共享判断与原文替换实现。
- build.mjs 生成 Egern 原生 ctx 模块脚本、四客户端原生请求/响应脚本，以及五份原生导入配置。
- test.mjs 直接读取生成的导入文件与运行脚本；只模拟宿主输入，不模拟真实广告已被移除。
- validation.json 记录本地检查结果与未完成的手机验收层次。

在此源码提交的完整检出中，先执行 node Source/MeituanWaimai/build.mjs 后执行 node Source/MeituanWaimai/test.mjs。构建默认采用 40 个 0 作为发布前固定引用占位符；真正发布时把源码提交 SHA 作为 build.mjs 的第一个参数，再执行测试和字节核对。

URL 和 JSON 字段参考公开作者的启动脚本与广告规则，运行代码独立实现。只处理已知开屏接口和广告素材；不批量导入第三方广告整包，不对首页商家/优惠券响应进行猜测式删除。

边界：无额外 HTTP、无持久缓存、无后台任务。原生脚本 8 秒；共享正文 2097152 个 UTF-16 单元、64 层、50000 扫描节点及扫描中 250 毫秒软预算。Egern/Surge/Shadowrocket 原生声明 2097152 字节上限。宿主读取和原生内存不受 JavaScript 长度检查保证。

检查日期：2026-10-20。尚未完成五客户端自身解析器、真实 iPhone/Android App 请求和界面验收；Shadowrocket 按公开兼容配置适配，未称为官方验证。
