# Country and Region Flags

249 ISO country and region flags rendered as 512 × 512 transparent-background PNG icons.

- File names use uppercase ISO 3166-1 alpha-2 codes.
- Includes `CN.png`, `HK.png`, `MO.png`, and `TW.png`.
- Each 4:3 flag is centered on a transparent square canvas without shadows or extra backgrounds.

Source SVGs: [lipis/flag-icons](https://github.com/lipis/flag-icons), licensed under the MIT License.
